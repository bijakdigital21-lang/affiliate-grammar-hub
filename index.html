✨ Cara Setup Page Affiliate ✨

Jom bina halaman promosi anda dengan mudah dan ceria! 🚀

1

Buka Menu Pages

Selepas register, pergi ke panel sebelah kiri dan tekan “pages”.

Tekan butang “Add pages”.

2

Create Page

Create new page. Masukkan apa sahaja nama dan nama ini untuk link URL kita nanti.

Selepas itu, tekan 'Create'.

3

Open in Editor

Teruskan dengan membuka editor halaman anda.

4

Import Template

Tekan pada simbol anak panah ke bawah untuk mula mengimport.

5

Masukkan Kod Template

Salin dan masukkan kod template ini, kemudian tekan import:

d66e1531-872a-4f35-b4c0-97a2df336400
6

Kemaskini Button WhatsApp

Scroll ke bawah dan tekan button WhatsApp > Attributes > masukkan link WhatsApp anda > tekan save.

7

Semak URL Page

Pergi semula ke paparan “pages” dan tekan link URL page anda untuk semak.

8

Mula Promosi! 🎉

Salin link ini dan anda sudah bersedia untuk mula mempromosikan produk! ✨
